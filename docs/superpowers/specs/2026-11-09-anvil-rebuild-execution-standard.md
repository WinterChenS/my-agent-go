# Anvil 重建分支实施与真实验收规范

2026-11-09 · `REBUILD-EXEC-SPEC` · 适用于 `codex/anvil-rebuild`

本规范补充[重建技术方案](./2026-11-09-anvil-prototype-rebuild-design.md)和[任务计划](../plans/2026-11-09-anvil-prototype-rebuild-plan.md)。G0 → G1 → G2 的阶段顺序、范围及通过条件继续按计划执行。

## 1. 由指定模型的 subagent 实现

- 每个实施 Task 交给使用 `deepseek-2/deepseek-v4.1-flash` 的 subagent。派发时提供 Task ID、依赖与允许修改的文件、失败用例、focused 验证及应交付的证据。主 Agent 负责任务调度、代码审查、真实验收和门禁判定。
- 派发前确认执行器能够选择这个模型。当前执行器没有该选项时，使用已配置且能明确选择该模型的 subagent 执行器。没有可用执行器、无法确认实际模型或调用失败且不能恢复时，将该实施任务记为 `BLOCKED`，保留原因与恢复条件。
- 每个 Task 记录 subagent 执行器、实际模型、运行 ID（如可取得）、验证结果与提交 SHA。`cmd/devtools` 等门禁代码沿用单写者规则。

## 2. 用 agent-desktop 验收真实桌面客户端

- 每个涉及桌面交互的 Task 都要在目标系统上打开当次构建的 Anvil Wails 客户端，使用 `agent-desktop` 技能完成实际操作。Windows 先跑 `agent-desktop status`，再加载平台说明，按“观察控件 → 执行操作 → 等待并核对状态”的顺序取证。
- 保存 Task ID、系统版本、客户端构建 SHA、实际命令与退出码、关键操作前后的 UI 快照或截图，以及证据路径和 SHA-256。原型截图对照、浏览器测试和单元测试分别作为补充证据。真实桌面用例要求可操作的桌面会话和客户端窗口，缺少任一前置时记为 `BLOCKED`。
- 阶段 0 的 UI 用例允许使用计划规定的原型场景数据，在真实客户端中操作验收。运行时发现和会话用例以实际宿主 CLI、界面状态和运行结果为准。

## 3. Pi 真实用例直接使用本机 Pi Agent

- Pi 发现、兼容探测、模型同步及会话验收直接使用用户机器上已安装的 Pi Agent，经 Anvil 正常的发现和运行入口连接。使用实际安装入口（如 `pi`），记录其解析路径和版本。禁止为验收另做 Pi 包装程序、替代实现或测试专用发行版。
- 用户授权使用本机 Pi 已配置的登录、模型和 token，验收可真实调用模型并产生 token 用量。无需另建测试账号、单独配置 token 或为验收封装 Pi。测试产生的 Anvil 数据、工作目录和测试会话仍单独存放。本条优先于旧文档中要求 Pi 使用独立登录或测试凭证的约定。
- 缺少本机 Pi、认证或满足要求的版本时，记录实际情况及对应的 `FAIL` 或 `BLOCKED`。不兼容版本被正确识别可作为该负例的证据，Pi 可用性与真实对话仍须单独取证。其他运行时继续按 G1/G2 计划取证。

## 4. 所有落盘数据限制在 D 盘

- Windows 上，从开发、构建、测试到客户端运行，所有新建或写入的文件、日志、缓存、临时文件和验收证据都必须实际落在 D 盘。重建分支的工作树使用 `D:\project\anvil-wt\anvil-rebuild`。额外的 subagent 工作树、任务产物和日志同样使用 D 盘。
- 启动工具前显式设置其可写目录。仓库内开发缓存和临时数据可放在已忽略的 `.tmp\`，为 `TEMP`、`TMP`、`TMPDIR`、`GOCACHE`、`GOMODCACHE`、npm 缓存、Playwright 浏览器下载和输出目录指定 D 盘路径。客户端的数据、配置、SQLite、日志、Wails/WebView2 用户数据目录和 agent-desktop 截图及跟踪也必须显式指向 D 盘。其他工具按其配置项设置所有写入位置。
- 路径检查须验证实际卷。解析相对路径、环境变量、符号链接和 junction 后，落点必须仍在 D 盘。发现目录缺失且可创建时在 D 盘创建。D 盘不可写、工具无法重定向，或无法确认它的写入位置时，停止该任务并记为 `BLOCKED`。应用和测试工具不得退回其他盘的默认目录。
- 唯一例外是本机 Pi Agent 自身产生的文件，可沿用它原来的位置。Anvil、测试脚本、适配器或其他工具为 Pi 写出的输入、日志和证据仍必须在 D 盘。
- `R0-00` 验证 D 盘正常路径可用、其他盘路径被拒绝、从 D 盘指向其他盘的重解析路径被拒绝，以及 D 盘不可写时不会回退。真实桌面证据记录应用、WebView2 和测试工具实际使用的数据及输出路径。此 Windows 落盘规则不授权在其他平台选用替代位置。
