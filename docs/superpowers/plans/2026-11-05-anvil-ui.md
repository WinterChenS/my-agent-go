# Anvil Product UI Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已批准的九页静态原型迁移为由真实 Go API、SQLite、Pi 和原生浏览器驱动的 Anvil 桌面 UI，并交付中英文、浅深主题和真机无障碍验收。

**Architecture:** React 页面只保存展示状态，业务状态来自 Wails 绑定的应用 API。沿用现有调用方式（`@wailsio/runtime` 的 `Call.ByName`、`frontend/src/app/useBackend.ts`、`frontend/src/runState.ts` 事件归约），不引入新的状态管理库。静态原型只作为视觉输入，禁止复制演示数字、连接状态、成功 toast 或权限默认值。

**Tech Stack:** React、TypeScript、Vite、Tailwind、shadcn、Vitest、Testing Library、Wails v3；U07 新增锁定版本的 Playwright 仅作预检。

**Spec:** `docs/superpowers/specs/2026-11-05-anvil-v1-product-ui-lifecycle-design.md`。

**Prototype input:** `docs/ui/Agent-客户端产品原型/`。

## Global Constraints

- 正式名称是 Anvil；用户可见入口使用 `Anvil.exe`、`Anvil.app`、`anvil`、`anvil://`、`ANVIL_*`。安装包、图标、URI 注册等打包元数据归 X03，本计划只改代码内名称、数据目录与环境变量。
- 仓库目录、Go module 和内部凭证服务标识 `cn.myagent.credentials` 本轮不改名：改服务标识会让已有 credentialRef 失效，违反规格 §4 “旧凭证继续通过已有 reference 使用”。
- `MYAGENT_*` 仅保留一个开发兼容周期，冲突时 `ANVIL_*` 优先，并记录弃用警告和配置来源。
- 支持 `zh-CN`、`en-US` 与 Light、Dark；“跟随系统”只是一种选择方式。
- 前端不得把 mock、hard-coded 统计、假 loading、点击后的直接成功 toast 当生产状态。
- 后端返回稳定错误 code 和参数；翻译只在前端发生。en-US 下不得显示 Go 返回的中文 message。
- 每个页面必须具备 loading、empty、error、permission denied、blocked 和 retry 状态。
- 前端按功能放置调用模块 `frontend/src/features/<feature>/api.ts`；`frontend/src/api.ts` 只保留共享的 `FQN`、run 事件与已有调用，避免成为多任务共享写点。
- 新增依赖必须锁定精确版本，并在同一提交更新 `frontend/package-lock.json` 与 `build/versions.lock.json`（F00 规则）。
- 共享写点 `internal/app/desktop.go`、`cmd/myagent/main.go`、`frontend/src/app/Router.tsx`、`frontend/src/app/navigation.ts`、`internal/contracts/*`、`schemas/*`、`tests/acceptance/cases.json` 同一时间只有一个写者，顺序见 master plan。
- 数据库迁移编号按 master plan 的迁移登记表分配，不得自行取号。
- 连接器与调度页面由 C08/C09 实现；本计划负责公共壳层、路由、一致性和跨页验收。
- 本计划的 case 声明 `oracleKind=external`：runner 必须写 `kind=external-observation` 的 `oracle.json`，`source` 取 `filesystem`（扫描报告/截图/录制）或 `database`（页面数值与 DB 对齐），并附目录内非空 artifact；截图哈希必须进 artifact 列表。纯 Playwright 截图不构成 external oracle。
